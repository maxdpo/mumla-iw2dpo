The fallback is hardcoded in Java as ARRAY_INPUT_METHOD_VOICE ("voiceActivity"), 
independent of whatever you put in the XML's android:defaultValue. 
The XML default only matters if something calls PreferenceManager.setDefaultValues() 
and no value is yet stored in SharedPreferences — and even then, this particular 
getter falls back to its own hardcoded string if the key is missing.

To actually make Push-to-talk the default, change the hardcoded fallback in Settings.java (around line 194), not just the XML:


java
public String getInputMethod() {
    String method = preferences.getString(PREF_INPUT_METHOD, ARRAY_INPUT_METHOD_PTT);
    if(!ARRAY_INPUT_METHODS.contains(method)) {
        // Set default method for users who used to use handset mode before removal.
        method = ARRAY_INPUT_METHOD_PTT;
    }
    return method;
}
